# Granthalay

सनातन प्रामाणिक पूजा ग्रन्थालय एवं पाण्डुलिपि डिजिटाइज़र (Sanskrit Scripture Digitizer & Reading Platform)

## Overview
Granthalay is an advanced scripture digitization, proofreading, and reader platform built for Vedic and classical Sanskrit texts. It features:
- **High-Fidelity OCR Post-Processing:** Automated healing of 800+ Devanagari ligatures (SanskritWeb / Ulrich Stiehl standards).
- **Vedic Svara Preservation:** Accurate stress mark preservation (Anudatta, Svarita, Dvisvarita).
- **Interactive Padachheda (पदच्छेद):** Paninian Sandhi-splitting engine (University of Hyderabad standards).
- **Bhojpatra Manuscript Folios:** Authentic Himalayan birch-bark manuscript generation with traditional red borders, auspicious emblems, and Devanagari typography.
- **Curated Scripture Collection:** 18 verified scriptures covering Vedic Suktas, Upanishads, Stotras, Darshana Shastras, and Karmakanda Paddhatis.

## Tech Stack
- **Frontend:** React, TypeScript, Vite, Tailwind CSS, Lucide Icons
- **Backend:** Node.js, Express, SQLite (`better-sqlite3`), Sharp
- **Processing:** Tesseract OCR, Paninian Linguistic Engine
