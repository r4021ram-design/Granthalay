# 🕉️ PUJA GRANTH DIGITIZER

## Master Full-Proof Development Prompt for Antigravity Agent

You are the lead software architect, senior full-stack engineer, OCR/document-processing engineer, Sanskrit/Devanagari text-processing specialist, QA engineer, and product designer responsible for building this application end-to-end.

The application is a **high-accuracy Puja Book / Sanskrit-Hindi Scripture Digitization and Verification System**.

The primary objective is:

> Take scanned Puja books, Sanskrit/Hindi religious books, PDFs, page images, or photographs and convert them into clean, structured, searchable, editable digital text while preserving the original scripture exactly and preventing OCR/AI hallucinations or silent textual alterations.

This is a **text-fidelity-first application**.

The system must NEVER prioritize visual cleanliness over source accuracy.

---

# 1. CORE PRODUCT PRINCIPLE

The application must follow this absolute rule:

> **NEVER silently change, invent, complete, normalize, translate, paraphrase, or hallucinate scripture text.**

OCR output is NOT automatically considered authoritative.

The original scanned/image source is the authority.

Whenever the system is uncertain, it must explicitly mark the text for human verification.

For religious/scriptural content:

```text
SOURCE IMAGE
     ↓
OCR
     ↓
VALIDATION
     ↓
CONFIDENCE ANALYSIS
     ↓
HUMAN VERIFICATION WHEN REQUIRED
     ↓
FINAL VERIFIED TEXT
```

Never:

```text
SOURCE IMAGE
     ↓
AI guesses what the verse probably says
     ↓
silently modifies it
```

# 66. FINAL ENGINEERING PRINCIPLE

The most important requirement of this entire application is:

> **Accuracy before automation.
> Source before AI.
> Verification before publication.
> Unicode fidelity before visual formatting.**

The application should behave like a professional digital preservation tool.

If there is ever a conflict between:

```text
Beautiful output
```

and

```text
Faithful source reproduction
```

choose:

# SOURCE FIDELITY.

If there is uncertainty:

# ASK FOR VERIFICATION.

If the OCR cannot read something:

# DO NOT GUESS.

If an AI model believes it knows the correct scripture:

# IT MUST NOT OVERRIDE THE SOURCE.

Build the application accordingly.
