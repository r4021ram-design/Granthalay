# Purana, Itihasa & Kavya Structural Taxonomy (महाकाव्य-पुराण-संरचना-तन्त्रम्)

## 1. Foundational Taxonomy & Structural Hierarchy (ग्रन्थ-पदानुक्रम)

This skill codifies the canonical computational hierarchy, metadata schema, and speaker indexing for sacred Sanskrit Epics (इतिहास), Mahapuranas (महापुराण), Upapuranas (उपपुराण), and Kavyas in Granthalay.

Traditional Sanskrit scriptures adhere to rigorous structural taxonomies:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       प्रमुख ग्रन्थ-पदानुक्रम संरचना                        │
└─────────────────────────────────────────────────────────────────────────────┘

१. श्रीमद्वाल्मीकीय रामायणम् (Itihāsa)
   └── काण्ड (Kāṇḍa - ७)
        └── सर्ग (Sarga - ६४५)
             └── श्लोक (Śloka - २४,०००)
                  └── पाद (Pāda - १/४ श्लोक)

२. महाभारतम् (Itihāsa)
   └── पर्व (Parva - १८)
        └── उप-पर्व (Upa-parva - १००)
             └── अध्याय (Adhyāya - २,०००+)
                  └── श्लोक (Śloka - १,००,०००)

३. श्रीमद्भागवतम् एवं अष्टादश महापुराणानि (Purāṇa)
   └── स्कन्ध / खण्ड / संहिता (Skandha / Khaṇḍa / Saṁhitā)
        └── अध्याय (Adhyāya)
             └── श्लोक / मन्त्र (Śloka / Mantra)

४. श्रीमद्भगवद्गीता (महाभारत भीष्मपर्वान्तर्गत)
   └── अध्याय (Adhyāya - १८)
        └── श्लोक (Śloka - ७००)

५. श्रीरामचरितमानस (अवधी-संस्कृत समन्वय)
   └── काण्ड (Kāṇḍa - ७)
        └── मङ्गलाचरण (संस्कृत श्लोक)
             └── दोहा / सोरठा (Dohā / Soraṭhā - क्रमांकित विश्राम)
                  └── चौपाई (Caupāī - प्रायः ४-८ चरण)
                       └── छन्द (Chhanda - विशेष स्तुति)
```

## 2. The 'Uvacha' (उवाच) Computational Architecture (वक्ता-पद्य-प्रबन्धन)

### २.१ ऐतिहासिक समस्या (The Classical Concordance Conflict)
ग्रन्थों में सम्भाषण के समय वक्ता-कथन आते हैं, जैसे:
- `धृतराष्ट्र उवाच` (Dhrtarashtra uvaca)
- `सञ्जय उवाच` (Sanjaya uvaca)
- `अर्जुन उवाच` (Arjuna uvaca)
- `श्रीभगवानुवाच` (Shri Bhagavan uvaca)
- `ऋषय ऊचुः` (Rishaya uchuh)
- `सूत उवाच` (Suta uvaca)

**प्रकाशनों में मतभेद**:
1. **गीता प्रेस (Gita Press) एवं पारम्परिक पाठ**: 'उवाच' को एक स्वतंत्र वक्ता-निर्देश (Speaker Header) माना जाता है। श्लोक संख्या केवल वास्तविक पद्य (Verse) को दी जाती है (उदा. गीता अध्याय १ में श्लोक १ धृतराष्ट्र के कथन के बाद प्रारम्भ होता है)।
2. **भाण्डारकर ओरिएंटल रिसर्च इंस्टीट्यूट (BORI Critical Edition)**: कुछ पाश्चात्य एवं आलोचनात्मक संस्करण 'उवाच' को अर्ध-श्लोक (Half-verse) मानकर श्लोक गणना में जोड़ देते हैं, जिससे सम्पूर्ण ग्रन्थ की नम्बरिंग विचलित हो जाती है।

### २.२ ग्रन्थालय का युगांतरकारी समाधान (Dual-Anchored Data Model)
ग्रन्थालय में श्लोक डेटाबेस में 'उवाच' को कभी भी मुख्य श्लोक संख्या विकृत करने की अनुमति नहीं दी जाएगी:

```typescript
interface PuranicVerseNode {
  // शास्त्रीय पदानुक्रम
  grantha_id: string;        // e.g., "gita", "valmiki_ramayana", "bhagavatam"
  section_type: "kanda" | "parva" | "skandha";
  section_number: number;    // e.g., 6 (भीष्मपर्व)
  chapter_number: number;    // e.g., 25 (गीता अ. १)
  verse_number: number;      // e.g., 1 (पारम्परिक गीता प्रेस क्रमांक)
  
  // वक्ता-निर्देशन (Uvacha Label)
  speaker?: {
    raw_text: string;        // "श्रीभगवानुवाच"
    speaker_name: string;    // "श्रीभगवान्" (भगवान् श्रीकृष्ण)
    verb: string;            // "उवाच" (अथवा "ऊचुः")
    is_standalone: boolean;  // true (पद्य से पृथक् शीर्ष पंक्ति)
  };

  // पद्य-सामग्री
  meter: string;             // "अनुष्टुप्", "त्रिष्टुप्"
  pada_count: number;        // प्रायः ४ पाद (दुर्लभ स्थलों पर ६ पाद / त्रिपाद)
  text_devanagari: string;   // शुद्ध श्लोक
  padaccheda: string[];      // पदच्छेद
  anvaya: string;            // गद्यान्वय
}
```

## 3. Structural Irregularities: Ardha-Shloka & Tri-pada (विषम पाद प्रबन्धन)

पुराणों और महाभारत में सामान्य ४-पाद (३२ अक्षर) के अतिरिक्त कुछ विशिष्ट संरचनाएं पाई जाती हैं:

1. **त्रिपाद श्लोक / षट्पाद श्लोक (6-Pada Verses - ४८ अक्षर)**:
   - कभी-कभी भाव की पूर्णता के लिए ऋषि अनुष्टुप् में २ पाद अतिरिक्त जोड़ देते हैं।
   - *प्रबन्धन*: इसे दो अलग श्लोक न मानकर `६-पाद श्लोक` के रूप में एक ही क्रमांक में संगृहीत किया जाए।
2. **अर्ध-श्लोक (2-Pada Single Line)**:
   - अध्याय के अन्त में या वक्ता-परिवर्तन के पूर्व कभी केवल एक पंक्ति (१६ अक्षर) आती है।
   - *प्रबन्धन*: इसे `[अर्ध-श्लोक]` फ्लैग के साथ सुरक्षित किया जाए ताकि पारायण का छन्द-प्रवाह न टूटे।
3. **गद्यात्मक मन्त्र (Puranic Prose Passages)**:
   - जैसे विष्णुपुराण, भागवत के पञ्चम स्कन्ध (भूगोल वर्णन) में गद्य आता है।
   - *प्रबन्धन*: इन्हें `is_prose: true` के साथ गद्य-खण्ड (Paragraph) के रूप में प्रदर्शित किया जाए।

## 4. Edition Alignment & Cross-Reference Concordance (संस्करण-तुलना)

ग्रन्थालय एक वैश्विक मानक स्थापित करता है जिससे पाठक किसी भी प्रमुख पारम्परिक संस्करण का सन्दर्भ खोज सके:

| ग्रन्थ | प्राथमिक आधार (Primary Authority) | द्वितीयक सन्दर्भ (Secondary Alignment) | विशिष्ट ध्यातव्य |
|---|---|---|---|
| **श्रीमद्भगवद्गीता** | **गीता प्रेस (Gorakhpur)** | BORI / शाङ्करभाष्य | कुल ७०० श्लोक मानक |
| **वाल्मीकि रामायण** | **गीता प्रेस (६४५ सर्ग)** | निर्णय सागर / बड़ौदा ओरिएंटल | उत्तरकाण्ड प्रबन्धन |
| **महाभारत** | **गीता प्रेस (चित्रात्मक)** | BORI Critical Edition | हरिवंश पुराण खिलपर्व के रूप में |
| **श्रीमद्भागवत** | **श्रीधरस्वामी टीका संस्करण** | गीता प्रेस / चौखम्बा | १२ स्कन्ध, ३३५ अध्याय |
| **दुर्गासप्तशती** | **कात्यायनी तन्त्र / डामर** | गीता प्रेस मार्कण्डेय पुराणान्तर्गत | ७०० मन्त्र गणना (उवाच मन्त्र सहित) |

## 5. UI Presentation & Recitation Guidelines in Granthalay

1. **वक्ता-प्रदर्शन (Speaker Badge)**:
   - 'उवाच' पंक्तियों को साधारण श्लोक की तरह न दिखाकर एक सम्मानीय **Liturgical Speaker Header** के रूप में केन्द्रित अथवा विशिष्ट वर्ण (`#8C2D19` सिन्दूरी) में प्रदर्शित किया जाए:
   ```
                         ॥ श्रीभगवानुवाच ॥
         कुतस्त्वा कश्मलमिदं विषमे समुपस्थितम्।
         अनार्यजुष्टमस्वर्ग्यमकीर्तिकरमर्जुन॥ २ ॥
   ```
2. **अध्याय-पुष्पिका (Colophon / Pushpika)**:
   - प्रत्येक अध्याय की समाप्ति पर आने वाली शास्त्रीय पुष्पिका को श्लोक संख्या से पृथक् 'Sacred Metadata' माना जाए:
   - *उदा.*: *इति श्रीमद्भगवद्गीतासूपनिषत्सु ब्रह्मविद्यायां योगशास्त्रे श्रीकृष्णार्जुनसंवादे अर्जुनविषादयोगो नाम प्रथमोऽध्यायः॥*
   - इसे रीडिंग मोड में अध्याय की पूर्णाहुति के रूप में भक्तिमय भाव से प्रदर्शित किया जाए।
