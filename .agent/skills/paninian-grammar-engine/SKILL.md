# Paninian Sanskrit Grammar Engine & Liturgical Standard (पाणिनीय-व्याकरण-तन्त्रम्)

## 1. Overview & Foundational Authority (सैद्धान्तिक भूमिका)

This skill serves as the canonical authority for **Paninian Computational Linguistics (पाणिनीय-व्याकरण-शास्त्र)** within Granthalay. It codifies the foundational rules of the **Trimuni Vyakaranam (त्रिमुनि-व्याकरणम्)**:
1. **Panini (महर्षि पाणिनि)** — *Sūtrakāra* (अष्टाध्यायी - सूत्रप्रणेता)
2. **Katyayana (महर्षि कात्यायन)** — *Vārtikakāra* (वार्तिककार)
3. **Patanjali (महर्षि पतञ्जलि)** — *Bhāṣyakāra* (महाभाष्यकार)
4. **Bhattoji Dikshita (भट्टोजि दीक्षित)** & **Varadaraja (वरदराज)** — *Prakriyākāra* (सिद्धान्तकौमुदी एवं लघुसिद्धान्तकौमुदी)

When analyzing, proofreading, typesetting, or segmenting Sanskrit verses (पद्य), Vedic suktas (ऋचा), stotras, or prose (गद्य), this engine enforces 100% fidelity to Paninian phonetics, morpho-phonology, and syntax.

### 2.2 It-Samjna & Pratyahara Derivation Rules (इत्-संज्ञा एवं प्रत्याहार-निर्माण)
1. **अन्त्यं हलित् स्यात्** — `हलन्त्यम्` (१.३.३): उपदेश में अन्तिम हल् वर्ण 'इत्' संज्ञक होता है। (ण्, क्, ङ्, च्, ट्, ण्, म्, ञ्, ष्, श्, व्, य्, र्, ल्)।
2. **उपदेशेऽजनुनासिक इत्** (१.३.२): उपदेश में अनुनासिक अच् वर्ण इत् संज्ञक होता है (विशेषतः सूत्र ६ में `लँ` का अकार, जिससे `र्` प्रत्याहार बनता है)।
3. **तस्य लोपः** (१.३.९): इत् संज्ञक वर्णों का लोप (अदर्शन) होता है, वे केवल प्रत्याहार-सीमा सूचक हैं।
4. **आदिरन्त्येन सहेता** (१.१.७१): अन्तिम इत् वर्ण के साथ आदि वर्ण मिलकर मध्यवर्ती सभी वर्णों का तथा अपना भी बोध कराता है। इसे **प्रत्याहार** कहते हैं।

## 3. Paniniya Shiksha: Phonetics, Sthana & Prayatna (पाणिनीय शिक्षा: स्थान एवं प्रयत्न)

### 3.1 The 8 Articulatory Locations (अष्टौ स्थानानि)
> **अष्टौ स्थानानि वर्णानामुरः कण्ठः शिरस्तथा।**  
> **जिह्वामूलं च दन्ताश्च नासिकौष्ठौ च तालु च॥**

```
1. कण्ठ्य:    अकुहविसर्जनीयानां कण्ठः       -> अ, आ, क-वर्ग (क, ख, ग, घ, ङ), ह, विसर्ग (ः)
2. तालव्य:   इचुयशानां तालु                -> इ, ई, च-वर्ग (च, छ, ज, झ, ञ), य, श
3. मूर्धन्य:  ऋटुरषाणां मूर्धा              -> ऋ, ॠ, ट-वर्ग (ट, ठ, ड, ढ, ण), र, ष
4. दन्त्य:    लृतुलसानां दन्ताः             -> ऌ, त-वर्ग (त, थ, द, ध, न), ल, स
5. ओष्ठ्य:   उपूपध्मानीयानाम् ओष्ठौ       -> उ, ऊ, प-वर्ग (प, फ, ब, भ, म), उपध्मानीय (ᳶ)
6. नासिक्य:  ञमङणनानां नासिका च           -> वर्ग पञ्चमाक्षर (नासिका + निज स्थान)
7. कण्ठतालु: एदैतोः कण्ठतालु              -> ए, ऐ
8. कण्ठोष्ठ: ओदौतोः कण्ठोष्ठम्            -> ओ, औ
9. दन्तोष्ठ: वकारस्य दन्तौष्ठम्            -> व
10. जिह्वामूल: जिह्वामूलीयस्य जिह्वामूलम्    -> जिह्वामूलीय (ᳵक, ᳵख)
11. केवलनासिक: नासिकाऽनुस्वारस्य           -> अनुस्वार (ं)
```

### 3.2 Internal & External Effort (आभ्यन्तर एवं बाह्य प्रयत्न)
- **आभ्यन्तर प्रयत्न (५ भेद)**:
  1. `स्पृष्टम्` — कादयो मावसानाः स्पर्शाः (क से म तक २५ स्पर्श वर्ण)।
  2. `ईषत्स्पृष्टम्` — अन्तस्थानाम् (य, र, ल, व)।
  3. `ईषद्विवृतम्` — ऊष्मणाम् (श, ष, स, ह)।
  4. `विवृतम्` — स्वराणाम् (समस्त अच् स्वर)।
  5. `संवृतम्` — ह्रस्वस्यावर्णस्य प्रयोगे संवृतम् (प्रक्रियादशायां तु विवृतमेव)।
- **बाह्य प्रयत्न (११ भेद)**:
  - खर् प्रत्याहार (`ख, फ, छ, ठ, थ, च, ट, त, क, प, श, ष, स`) = **विवार, श्वास, अघोष**।
  - हश् प्रत्याहार (`ह, य, व, र, ल, ञ, म, ङ, ण, न, झ, भ, घ, ढ, ध, ज, ब, ग, ड, द`) = **संवार, नाद, घोष**।
  - वर्ग १, ३, ५ + यण् = **अल्पप्राण**।
  - वर्ग २, ४ + शल् = **महाप्राण**।
  - समस्त स्वर = **उदात्त, अनुदात्त, स्वरित**।

## 4. The Complete Paninian Sandhi System (संहिता एवं सन्धि-शास्त्र)

> **परः संनिकर्षः संहिता** (१.४.१०९) — वर्णों की अत्यन्त सन्निकटता को संहिता कहते हैं।

### 4.1 Ach Sandhi (अच् स्वर सन्धि)

| क्र. | सन्धि नाम | प्रमुख पाणिनीय सूत्र | नियम (Condition -> Result) | उदाहरण (विच्छेद = सन्धि) |
|---|---|---|---|---|
| १ | **यण् सन्धि** | `इको यणचि` (६.१.७७) | `इक्` + असवर्ण `अच्` -> `यण्` | `यदि + अपि = यद्यपि`, `इति + आदि = इत्यादि`, `मधु + अरि = मध्वरि`, `मातृ + आज्ञा = मात्राज्ञा` |
| २ | **अयादि सन्धि** | `एचोऽयवायावः` (६.१.७८) | `ए, ओ, ऐ, औ` + `अच्` -> `अय, अव्, आय, आव्` | `ने + अनम् = नयनम्`, `पो + अनः = पवनः`, `नै + अकः = नायकः`, `पौ + अकः = पावकः` |
| ३ | **गुण सन्धि** | `आद्गुणः` (६.१.८७) | `अ / आ` + `इक्` -> गुण (`ए, ओ, अर्, अल्`) | `नर + इन्द्र = नरेन्द्र`, `महा + उत्सव = महोत्सव`, `देव + ऋषि = देवर्षि`, `तव + ऌकार = तवल्कार` |
| ४ | **वृद्धि सन्धि** | `वृद्धिरेचि` (६.१.८८) | `अ / आ` + `एच` -> वृद्धि (`ऐ, औ`) | `एक + एकम् = एकैकम्`, `मत + ऐक्यम् = मतैक्यम्`, `महा + औषधि = महौषधि` |
| ५ | **दीर्घ सन्धि** | `अकः सवर्णे दीर्घः` (६.१.१०१) | `अक्` + सवर्ण `अक्` -> दीर्घ स्वर | `दैत्य + अरिः = दैत्यारिः`, `श्री + ईशः = श्रीशः`, `भानु + उदयः = भानूदयः`, `होतृ + ऋकार = होतॄकार` |
| ६ | **पूर्वरूप सन्धि** | `एङः पदान्तादति` (६.१.१०९) | पदान्त `ए / ओ` + ह्रस्व `अ` -> पूर्वरूप (`ऽ` अवग्रह) | `हरे + अव = हरेऽव`, `विष्णो + अव = विष्णोऽव`, `शिवो + अहम् = शिवोऽहम्` |
| ७ | **पररूप सन्धि** | `एङि पररूपम्` (६.१.९४) | अकारान्त उपसर्ग + `ए / ओ` धातु -> पररूप | `प्र + एजते = प्रेजते`, `उप + ओषति = उपोषति` |
| ८ | **प्रकृतिभाव** | `प्लुतप्रगृह्या अचि नित्यम्` (६.१.१२५) | प्रगृह्य संज्ञक (`ईदूदेद् द्विवचनं प्रगृह्यम्`) + अच् -> सन्धि अभाव | `हरी + एतौ = हरी एतौ`, `विष्णू + इमौ = विष्णू इमौ`, `गङ्गे + अमू = गङ्गे अमू` |

### 4.2 Hal Sandhi (हल् व्यञ्जन सन्धि)

| क्र. | सन्धि नाम | प्रमुख पाणिनीय सूत्र | नियम (Condition -> Result) | उदाहरण (विच्छेद = सन्धि) |
|---|---|---|---|---|
| १ | **श्चुत्व सन्धि** | `स्तोः श्चुना श्चुः` (८.४.४०) | `स / त-वर्ग` + `श / च-वर्ग` योग -> `श / च-वर्ग` | `सत् + चित् = सच्चित्`, `रामस् + चिनोति = रामश्चिनोति`, `कस् + चित् = कश्चित्`, `शार्ङ्गिन् + जय = शार्ङ्गिञ्जय` |
| २ | **ष्टुत्व सन्धि** | `ष्टुना ष्टुः` (८.४.४१) | `स / त-वर्ग` + `ष / ट-वर्ग` योग -> `ष / ट-वर्ग` | `तत् + टीका = तट्टीका`, `रामस् + टीकते = रामष्टीकते`, `इष् + त = इष्ट`, `कृष् + न = कृष्ण` |
| ३ | **जश्त्व (पदान्त)** | `झलां जशोऽन्ते` (८.२.३९) | पदान्त `झल्` -> `जश्` (३य वर्ण: ग, ज, ड, द, ब) | `वाक् + ईशः = वागीशः`, `जगत् + ईशः = जगदीशः`, `अच् + अन्तः = अजन्तः`, `चित् + रूपम् = चिद्रूपम्` |
| ४ | **जश्त्व (अपदान्त)**| `झलां जश् झशि` (८.४.५३) | अपदान्त `झल्` + `झश्` -> `जश्` | `बुध् + धी = बुद्धि`, `क्रुध् + ध = क्रुद्ध`, `सिध् + ध = सिद्ध` |
| ५ | **चर्त्व सन्धि** | `खरि च` (८.४.५५) | `झल्` + `खर्` (कठोर) -> `चर्` (१म वर्ण: क, च, ट, त, प) | `सद् + कारः = सत्कारः`, `उद् + पन्न = उत्पन्न`, `दिग् + पाल = दिक्पाल` |
| ६ | **अनुनासिक सन्धि**| `यरोऽनुनासिकेऽनुनासिको वा` (८.४.४५) | पदान्त `यर्` + अनुनासिक -> अनुनासिक (५म वर्ण) | `वाक् + मयम् = वाङ्मयम्`, `जगत् + नाथः = जगन्नाथः`, `षट् + मुखः = षण्मुखः` |
| ७ | **अनुस्वार सन्धि**| `मोऽनुस्वारः` (८.३.२३) | पदान्त `म्` + `हल्` -> अनुस्वार (`ं`) | `हरिम् + वन्दे = हरिं वन्दे`, `गृहम् + गच्छति = गृहं गच्छति` |
| ८ | **परसवर्ण सन्धि** | `अनुस्वारस्य ययि परसवर्णः` (८.४.५८) | `ं` + `यय्` -> वर्ग का ५म वर्ण | `शं + कः = शङ्कः`, `सं + घः = सङ्घः`, `अं + चित = अञ्चित`, `कुं + ठ = कुण्ठ` |
| ९ | **लत्व (परसवर्ण)**| `तोर्लि` (८.४.६०) | `त-वर्ग` + `ल` -> `ल्` (न का लूँ) | `तत् + लयः = तल्लयः`, `विद्वान् + लिखति = विद्वाँल्लिखति` |
| १० | **तुगागम सन्धि** | `छे च` (६.१.७३) | ह्रस्व स्वर + `छ` -> `त्` का आगम (`च्छ`) | `शिव + छाया = शिवच्छाया`, `तरु + छाया = तरुच्छाया`, `अनु + छेद = अनुच्छेद` |
| ११ | **ङमुडागम** | `ङमो ह्रस्वादचि ङमुण्नित्यम्` (८.३.३२) | ह्रस्व + पदान्त `ङ, ण, न` + `अच्` -> द्वित्व आगम | `प्रत्यङ् + आत्मा = प्रत्यङ्ङात्मा`, `कुर्वन् + आस्ते = कुर्वन्नास्ते` |

### 4.3 Visarga Sandhi (विसर्ग सन्धि)

> **विसर्ग की मूल प्रकृति 'स्' अथवा 'र्' (रुँ) है — `ससजुषो रुः` (८.२.६६)।**

| क्र. | अवस्था एवं पाणिनीय सूत्र | नियम | उदाहरण |
|---|---|---|---|
| १ | **सत्व বিধান**<br>`विसर्जनीयस्य सः` (८.३.३४) | विसर्ग + `खर्` (`क, ख, प, फ` छोड़कर च, छ, ट, ठ, त, थ) -> `स्` | `नमः + ते = नमस्ते`<br>`इतः + ततः = इतस्ततः`<br>`कः + चित् = कश्चित्` (`स्तोः श्चुना श्चुः` से) |
| २ | **उत्व विधान (१)**<br>`अतो रोरप्लुतादप्लुते` (६.१.११३) | ह्रस्व `अ` + `ः` (`रुँ`) + ह्रस्व `अ` -> `उ` मिलकर `ओ` + अवग्रह `ऽ` | `शिवः + अर्च्यः = शिवोऽर्च्यः`<br>`कः + अयम् = कोऽयम्`<br>`रामः + अवदत् = रामोऽवदत्` |
| ३ | **उत्व विधान (२)**<br>`हशि च` (६.१.११४) | ह्रस्व `अ` + `ः` (`रुँ`) + `हश्` (मृदु व्यञ्जन) -> `ओ` | `शिवः + वन्द्यः = शिवो वन्द्यः`<br>`रामः + नमती = रामो नमति`<br>`मनः + हरः = मनोहरः`<br>`तेजः + मयम् = तेजोमयम्` |
| ४ | **यत्व एवं विसर्ग लोप**<br>`भोभगोअघोअपूर्वस्य योऽशि` (८.३.१७)<br>`लोपः शाकल्यस्य` (८.३.१९) | `भोस्, भगोस्, अघोस्` अथवा `आ` + `ः` + `अश्` वर्ण -> यकार लोप (विसर्ग लोप) | `देवाः + आगताः = देवा आगताः`<br>`भोः + देवाः = भो देवाः`<br>`नराः + हसन्ति = नरा हसन्ति` |
| ५ | **रुत्व एवं दीर्घादेश**<br>`रो रि` (८.३.१४)<br>`ढ्रलोपे पूर्वस्य दीर्घोऽणः` (६.३.१११) | `र्` + `र्` -> पूर्व रकार का लोप तथा पूर्व स्वर का दीर्घ | `पुनर् + रमते = पुना रमते`<br>`हरिः + रम्यः = हरी रम्यः`<br>`शम्भुः + राजते = शम्भू राजते` |
| ६ | **सः / एषः सुलोप**<br>`एतत्तदोः सुलोपोऽकोरनञ्पमासे हलि` (६.१.१३२) | `सः` और `एषः` के आगे कोई भी व्यञ्जन (`हल्`) आये तो विसर्ग का नित्य लोप होता है | `सः + गच्छति = स गच्छति` (न कि सः गच्छति)<br>`एषः + पठति = एष पठति` |

## 5. Padaccheda Architecture: Subanta, Tinganta & Avyaya (पदच्छेद-सिद्धान्त)

> **सुप्तिङन्तं पदम्** (१.४.१४) — सुप्-प्रत्ययान्त एवं तिङ्-प्रत्ययान्त शब्द की 'पद' संज्ञा होती है। बिना पद बने कोई भी शब्द संस्कृत में प्रयुक्त नहीं हो सकता (*नापदं शास्त्रे प्रयुञ्जीत*)।

## 6. Samasa Analysis (समास-विग्रह विधान)

> **समर्थः पदविधिः** (२.१.१) — पदों का पारस्परिक अन्वय होने पर ही समास होता है।

1. **अव्ययीभाव (पूर्वपदप्रधान)**:
   - उदा. `यथाशक्ति` = शक्तिम् अनतिक्रम्य। `प्रतिदिनम्` = दिने दिने इति। `उपकष्णम्` = कृष्णस्य समीपम्।
2. **तत्पुरुष (उत्तरपदप्रधान)**:
   - द्वितीया तत्पुरुष: `कृष्णश्रितः` = कृष्णं श्रितः।
   - तृतीया तत्पुरुष: `हरित्रातः` = हरिणा त्रातः।
   - चतुर्थी तत्पुरुष: `भूतबलिः` = भूतेभ्यः बलिः।
   - पञ्चमी तत्पुरुष: `चोरभयम्` = चोरात् भयम्।
   - षष्ठी तत्पुरुष: `राजपुरुषः` = राज्ञः पुरुषः। `देवालयः` = देवानाम् आलयः।
   - सप्तमी तत्पुरुष: `अक्षशौण्डः` = अक्षेषु शौण्डः।
3. **कर्मधारय (विशेषण-विशेष्य / उपमान-उपमेय तत्पुरुष)**:
   - `नीलोत्पलम्` = नीलं च तत् उत्पलं च।
   - `घनश्यामः` = घन इव श्यामः।
   - `मुखचन्द्रः` = मुखमेव चन्द्रः।
4. **द्विगु (संख्यापूर्वः कर्मधारयः)**:
   - `पञ्चवटी` = पञ्चानां वटानां समाहारः।
   - `त्रिभुवनम्` = त्रयाणां भुवनानां समाहारः।
5. **द्वन्द्व (उभयपदप्रधान)**:
   - इतरेतर द्वन्द्व: `रामलक्ष्मणौ` = रामश्च लक्ष्मणश्च। `मातापितरौ` = माता च पिता च।
   - समाहार द्वन्द्व: `पाणिपादम्` = पाणी च पादौ च एषां समाहारः।
6. **बहुव्रीहि (अन्यपदप्रधान)**:
   - `पीताम्बरः` = पीतं अम्बरं यस्य सः (श्रीविष्णुः)।
   - `चन्द्रशेखरः` = चन्द्रः शेखरे यस्य सः (भगवान् शिवः)।
   - `दशाननः` = दश आननानि यस्य सः (रावणः)।

## 7. Operational Scripture Proofreading Rules (ग्रन्थालय-शोधन नियम)

When proofreading Sanskrit and Vedic texts in Granthalay, apply this Paninian rulebook to eradicate OCR flaws:

### 7.1 Rule P-1: Prohibition of Visarga Before Consonants in 'Sa' and 'Esha'
- **सूत्र**: `एतत्तदोः सुलोपोऽकोरनञ्पमासे हलि` (६.१.१३२)
- **OCR त्रुटि**: `सः गच्छति`, `एषः पठति`, `सः ददर्श`
- **शुद्ध पाणिनीय पाठ**: `स गच्छति`, `एष पठति`, `स ददर्श`
- **अपवाद**: स्वर परे होने पर सन्धि होगी (`सः + अवदत् = सोऽवदत्`, `सः + आगच्छति = स आगच्छति`)।

### 7.2 Rule P-2: Parasavarna vs. Anusvara in Scripture Body
- **सूत्र**: `अनुस्वारस्य ययि परसवर्णः` (८.४.५८) एवं `वा पदान्तस्य` (८.४.५९)
- परम्परागत मुद्रण तथा पाणिनीय संहिता पाठ में वर्ग के भीतर पञ्चमाक्षर (परसवर्ण) शुद्धतम है:
  - `गंगा` -> **`गङ्गा`**
  - `शंख` -> **`शङ्ख`**
  - `पंच` -> **`पञ्च`**
  - `पंडित` -> **`पण्डित`**
  - `संत` -> **`सन्त`**
  - `अंबा` -> **`अम्बा`**

### 7.3 Rule P-3: Strict Distinction Between Ksh / Jñ and Plain Ligatures
- **क्ष** = `क्` + `ष` (मूर्धन्य षकार)
- **ज्ञ** = `ज्` + `ञ` (तालव्य ज्ञकार, न कि ग्य)
- OCR प्रायः `ज्ञ` को `ज्य` या `ग्य` बना देता है — इसे तुरन्त `ज्ञ` में पुनः स्थापित करें।

### 7.4 Rule P-4: Vedic Accents (उदात्त, अनुदात्त, स्वरित) Integrity
- ऋग्वेद एवं यजुर्वेद मन्त्रों में पाणिनीय स्वर-विधान (`उच्चैरुदात्तः` १.२.२९, `नीचैरनुदात्तः` १.२.३०, `समाहारः स्वरितः` १.२.३१):
  - अनुदात्त: पद के नीचे क्षैतिज रेखा `॒` (`\u0952`)
  - स्वरित: पद के ऊपर लम्बवत् रेखा `॑` (`\u0951`)
  - कभी भी अनुदात्त को अंडरलाइन या हाइफन (`-`, `_`) और स्वरित को इनवर्टेड कॉमा (`'`, `"`) न रहने दें।
